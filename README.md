# 🛒 Inventory & Shop System Reimagined (Unity & C#)

Reimagining RPG economy mechanics with a modular, scalable Inventory & Shop system built in **Unity**, powered by **ScriptableObjects**, **MVC**, and **Service Locator** patterns.

---

## 🚀 Overview

This system blends **clean architecture** with **gameplay flexibility**, featuring:
- Dual-panel UI for Shop and Player Inventory
- Real-time currency and weight tracking
- Item metadata-driven logic using ScriptableObjects
- Dynamic filtering, contextual detail panels, and quantity selection

---

## ✨ Features

- 🧠 Designed with **MVC**, **Observer**, and **Service Locator** patterns
- 🧱 Built for **scalability**, **testability**, and **modular extension**
- 🖼️ Dynamic grid-based UI with tabbed filtering by item type
- 💰 Currency & weight enforcement with reactive UI feedback
- 🧪 Quantity selection via popup with +/- controls and confirmation modal
- 🎲 Rarity-based item generation using weighted probability curves
- 🔊 Overlay feedback with audio cues and timed fadeouts

---

## 🔑 Key Learnings

- ✅ Applied **SOLID principles** and **SRP/DRY** across UI and logic layers  
- 🧩 Mastered **ScriptableObject-driven data architecture**  
- 🔄 Implemented **reactive UI updates** via Observer pattern  
- 🧪 Built **modular services** for Currency, Inventory, Audio, and Popups  
- 🧠 Validated design for future extensibility (crafting, upgrades, etc.)
